# Atheeq Syed — Portfolio

Personal portfolio for AI strategy and product management roles.

## Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS v4
- EN / FR / AR i18n with RTL support

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Deploy on Vercel

1. Push this repo to GitHub.
2. Import the project at [vercel.com/new](https://vercel.com/new).
3. Deploy (framework preset: Next.js).
4. Add a custom domain under **Project → Settings → Domains** (e.g. `atheeqsyed.com`).

Resume file lives at `public/resume/Atheeq_Syed_Resume.pdf`.
